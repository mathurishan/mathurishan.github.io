This is my personal portfolio website, showcasing my projects in Data Analytics, Business Intelligence, and Project Management. The site highlights case studies, Power BI dashboards, analytics reports, and other work I’ve completed for employers, university courses, and personal learning.

The design is powered by Forty, a responsive HTML5/CSS3 template by HTML5 UP. I customized the layout and content to create a clean project-tile interface that links to detailed pages for each project.

Responsive, modern layout suitable for desktop & mobile
